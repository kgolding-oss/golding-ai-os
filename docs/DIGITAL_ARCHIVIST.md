# Digital Archivist

The Digital Archivist converts Mac Knowledge Vault metadata into an executive report. It summarizes total files, storage, top categories, extensions, largest files, largest folders, cache signals, developer/system file signals, media archives, legal/immigration concentration, funding concentration, business concentration, and next safe actions.

All cleanup and archive recommendations are advisory only. No cleanup execution exists in this milestone.

## Insight primitives

The archivist identifies oversized files, repeated filenames, temporary/cache locations, virtual machine images, installer files, media project files, large email archives, and categories requiring human review. These are metadata-only signals and are not proof of duplicate content.

# Executive Office

The Executive Office dashboard is the daily control surface for The Law Library OS. Each morning it presents:

- Executive Briefing
- Priority Queue
- Urgent Cases
- Upcoming Hearings
- Grant Deadlines
- Sponsor Pipeline
- Donor Pipeline
- Financial Snapshot
- Property Updates
- AI Recommendations
- Pending Approvals
- System Health

The dashboard component is reusable and draws from the Law Library OS activation registry in `lib/law-library-os`.

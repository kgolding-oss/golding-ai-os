# Plugin Developer Guide

1. Create a manifest with the SDK.
2. Declare capabilities and dependencies.
3. Add white-label branding and compatibility scopes.
4. Declare permissions, external APIs, storage, network access, approval requirements, and audit events.
5. Register the manifest in the catalog or through a future marketplace feed.
6. Use the loader to install and enable the plugin.

Do not modify core platform code for customer-specific functionality. Build a plugin instead.

# What-If Analysis

What-If Analysis lets Executive Command compare multiple strategies side by side before making a decision. `compareScenarios` runs each typed scenario against the current Digital Twin and produces a comparison matrix for cost, risk, time, workload, funding, success probability, and confidence.

## Executive dashboard

The Digital Twin dashboard component shows:

- Active simulations.
- Recommended scenario.
- Predicted bottlenecks.
- Projected KPI changes.
- Confidence.
- Side-by-side scenario comparison.
- Per-scenario risks, approval impact, and recommended actions.

## Governance

What-if outputs are advisory. They do not approve, schedule, or execute work. Legal, financial, filing, outreach, connector-write, and payment actions remain approval-gated and must pass existing GAIOS governance policies before execution.

# Golding AI OS

Sprint 1 MVP.

## Includes

- Dashboard shell
- CEO command panel UI
- Business lanes
- Approval queue
- Task list
- Audit log
- Next.js setup for Vercel

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy on Vercel

1. Import this repository into Vercel.
2. Framework preset: Next.js.
3. Build command: npm run build.
4. Deploy.
5. Add custom domain: os.thalawlibrary.org.
